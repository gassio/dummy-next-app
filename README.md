# dummy-next-app

A minimal Next.js app for trying out Vercel deploys.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this repo to GitHub.
2. In Vercel, click **Add New → Project**, import the repo, and hit **Deploy** (defaults work).
3. Every push to `main` deploys to production; other branches/PRs get preview URLs.

The home page shows the Vercel environment (`production` / `preview`) and commit SHA, so you can see which deploy you're looking at.
